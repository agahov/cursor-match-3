# cursor-match3

Self-improving game-development workflow. Match-3 design is cycle 1.

- `wiki/` — game design. Game terms: `wiki/glossary.md`
- `architecture/` — ADRs, tech stack
- `spec/` — Roadmap and Features
- `process/` — loop (`LOOP.md`, `phases.md`) and process terms (`process/glossary.md`)
- `.cursor/rules/` — short invariants. `.cursor/skills/` — procedures

A `sessionStart` hook injects `process/LOOP.md`. Follow that Phase only.
