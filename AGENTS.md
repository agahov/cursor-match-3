# cursor-match3

Workflow kit plus one test game (Match-3). 

- `wiki/` — game design (`index.md`). Game terms: `wiki/glossary.md`
- `architecture/` — ADRs, tech stack (`index.md`)
- `spec/` — Roadmap (`ROADMAP.md`) and Features
- `process/` — live loop (`LOOP.md`), playbooks, process terms (`process/glossary.md`)
- `.cursor/rules/` — short invariants. `.cursor/skills/` — procedures

A `sessionStart` hook injects `process/LOOP.md`. Follow that Phase only.
