# Reflect cycle

1. Read `process/LOOP.md`, the Feature `review.md`, and [`process/OPEN_QUESTIONS.md`](../../../process/OPEN_QUESTIONS.md).
2. Write `process/reflections/cycle-N.md`: what worked, what hurt, **concrete edits** (path + change), deferred questions.
3. Apply those edits in this Phase (or wait if the user wants to approve first).
4. Set `process/LOOP.md` to the next Cycle, Phase **research**, and a next action.
